Adds `tinydb.operations.append(field, value)` as requested in the linked issue.

- Appends to an existing list
- Creates the list when the document doesn't have the field yet
- Raises `TypeError` if the field exists but is not a list

Implemented the same way as the other operations (returns a transform function), with tests for the existing-list and missing-field cases. All tests pass; this is a small, self-contained addition.
