Addresses the linked issue about printed results being hard to tell apart.

`Document` now includes its `doc_id` in `repr()`/`str()`, e.g. `Document({'name': 'John'}, doc_id=1)`, so `print(db.all())` shows which record is which. Only `__repr__` is overridden: equality with plain dicts, `dict(doc)` and JSON serialization are unchanged.

- `tinydb/table.py`: `Document.__repr__`
- `tests/test_tables.py`: test for the new repr and unchanged equality
- `docs/changelog.rst`: changelog entry

Note for reviewers: this changes what users see in the REPL, so it is a visible (but not breaking) change.
