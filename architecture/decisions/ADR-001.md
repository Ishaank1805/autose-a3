# ADR-001 — Divide the workflow into five model roles, with one planner covering requirements and design

**Status:** Accepted — baseline

## Context

The assignment fixes six SDLC stages, but the stages do not require six equally independent agents. Requirements and design are tightly coupled: both need repository reading, the A1 specification skill, and A2's `ARCHITECTURE.md`. Implementation and test authorship should be separated because an implementer can otherwise encode its mistaken interpretation into the tests. Review must be independent of all earlier reasoning. A further question is whether acceptance-criterion testability should be judged by the planner itself.

The bundle supports a `single-agent` variant in which one shared session performs stages 1–4. It also contains separate prompts and tool sets for a planner, implementer, test author, reviewer, and a testability judge.

## Decision

Use five model roles in the baseline:

1. **Planner (Sonnet)** owns stage 1, Requirements, and stage 2, Design. It uses the A1 skill to produce `spec.md`, then uses `ARCHITECTURE.md` and source inspection to produce `design.md`.
2. **Testability judge (Haiku)** has no tools and only judges whether an already structured acceptance criterion is testable. It is an additional check, not the author of the specification.
3. **Implementer (Sonnet)** owns stage 3 and may edit only configured source and documentation paths.
4. **Test author (Sonnet)** owns stage 4 and may write only `tests/test_issue_<N>.py`.
5. **Reviewer (Opus)** owns stage 6 in a fresh job and has no GitHub credential in its model process.

Stage 5 is intentionally deterministic: release is performed by the harness, not a model.

## Consequences

This keeps requirements and design coherent without carrying a single conversation through code generation and testing. Separating implementation from test authorship makes “the code passes its own tests” weaker as a failure mode. The inexpensive judge adds a second view of testability, and the stronger reviewer is reserved for the highest-value sceptical task. The trade-off is more model calls and artifact hand-offs. The `single-agent` variant is retained as a D1 experiment: compare stage pass rate, token use, hidden-test pass rate, and reviewer findings rather than assuming decomposition is beneficial.
