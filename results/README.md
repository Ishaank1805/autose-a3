# Results

Generated by `experiment/scripts/collect_results.py` from real runs. Do not edit the generated files by hand.

- `results.csv`: one row per AutoSE run. Columns: run id/link, mode (full/review), variant, issue, PR, head commit, outcome (approved, changes_requested, stopped, review_error, error), final status of each stage in round 0, review verdicts per round, seeded-PR ground truth and whether the reviewer was right, hidden tests passed/total on the run's head commit, failed checks, loops, tokens (uncached input, output, cache read, cache write, total) and estimated cost.
- `runs.md`: links to every run, PR and review.
- `figures/`: stage pass rate, hidden tests, seeded-PR reviews and tokens per run (`make_figures.py`).
- `summary.md`: stage pass rates, hidden-test results, reviewer accuracy on the seeded PRs, and the reviewer's main findings (what it caught and where it was wrong).
- `fixes.md`: every change made to the provided code or configuration after the first runs, with the reason.
